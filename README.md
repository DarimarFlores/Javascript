Requisitos funcionais 
1. O sistema deve permitir que o usuário adicione novas tarefas colocando uma descrição.
2. O sistema deve listar todas as tarefas cadastradas, exibindo a descrição e o status (concluída ou pendente).
3. O sistema deve permitir que o usuário marque uma tarefa como concluída, deve ser atualizado visualmente riscando o texto.
4. O sistema deve permitir que ao usuário excluir uma tarefa da lista.
5. O sistema deve permitir que o usuário filtre a exibição das tarefas como: todas, concluídas e pendentes.
6. O sistema deve salvar as tarefas no armazenamento local do navegador (localStorage).
    
Requisitos não funionais
1. O sistema deve adaptando-se a diferentes tamanhos de tela (desktop, tablet e mobile).
2. O sistema deve ser simples e intuitivo de usar, com botões e ações claramente identificados.
3. O sistema deve carregar rapidamente (preferencialmente em menos de 2 segundos).
4. O sistema deve funcionar corretamente nos principais navegadores.
5. O código-fonte deve ser escrito seguindo boas práticas de organização, clareza e semântica.

Modelo de negocio Freemium + Premium
Oferecer uma versão gratuita com funcionalidades básicas, e cobrar pela versão premium com funções avançadas oferecendo um período de teste grátis (7 ou 14 dias).
